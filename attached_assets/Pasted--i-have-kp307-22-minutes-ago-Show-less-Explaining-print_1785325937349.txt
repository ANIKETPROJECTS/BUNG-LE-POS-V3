Explaining printer connectivity and protocols

Explaining printer connectivity and protocols
Got it — the Shreyans KP307. It's an Indian thermal printer (80mm) with WiFi, Ethernet, USB and Bluetooth. It uses the standard ESC/POS protocol — same as Epson, Star, etc. Good news: this is a very well-supported printer.

Here's the Reality of WiFi Printing from a Browser
Your KP307 connects to WiFi and gets an IP like 192.168.1.50. It listens for print commands on TCP port 9100.

The problem: browsers cannot make raw TCP connections for security reasons. So even though your browser and printer are on the same WiFi, the browser can't directly talk to port 9100. It's a browser security wall, not a network problem.

The Clean Solution: QZ Tray
This is exactly how Petpooja, POSist, and most Indian cloud POS systems solve this. It's called QZ Tray.

[Cloud POS in browser]
        ↓  WebSocket (localhost)
   [QZ Tray - runs silently in system tray]
        ↓  Raw ESC/POS over TCP port 9100
   [KP307 WiFi Printer at 192.168.1.50]

What QZ Tray is:

A free, open-source small app (~15MB)
Installs once on the billing counter PC
Sits silently in the Windows system tray
Acts as a bridge between the browser and any local printer
What you do:

Restaurant installs QZ Tray once
Your POS connects to it via WebSocket on localhost
When cashier clicks Print, your app sends raw ESC/POS commands through QZ Tray to the KP307
Bill prints instantly — no print dialog, no popup, fully automatic

Explaining QZ Tray integration workflow

Explaining QZ Tray integration workflow
Here's exactly how it would work, step by step.

Part 1 — What Gets Built (One Time, By You)
Step 1 — Add a Printer Settings Page to Your POS
In your existing Settings section, you'd add a "Printer Setup" screen where the restaurant enters:

Printer IP address (e.g. 192.168.1.50) — they find this by pressing the test button on KP307
Printer port (always 9100 for ESC/POS — pre-filled, they don't touch it)
Paper width (80mm — pre-filled for KP307)
This gets saved in MongoDB against that restaurant's account.

Step 2 — Build a Print Service in Your Frontend
A small JavaScript module in your React app that:

On page load, connects to QZ Tray running on localhost:8181 via WebSocket
Checks if QZ Tray is running (if not, shows a "Printer not connected" warning)
Exposes a printBill(orderData) function that the rest of the app calls
Step 3 — Format Bills as ESC/POS Commands
ESC/POS is a set of simple text commands that tell the printer things like:

Make text bold
Center this line
Draw a divider line
Cut the paper
You'd write a bill formatter that takes an order from your POS and converts it into these commands — restaurant name at top, items, totals, then auto-cut.

Step 4 — Connect Print Buttons to the Print Service
Wherever "Print Bill" or "Print KOT" buttons exist in your app, they call printBill(orderData). The print service sends the job to QZ Tray → QZ Tray sends to KP307 → paper comes out. No dialog, no click.

Part 2 — What Happens at Each Restaurant (One Time Setup)
Step 1 — Connect KP307 to WiFi
The restaurant does this once using the Shreyans WiFi setup tool (already included with the printer). The printer gets a local IP address.

Step 2 — Find the Printer's IP
They press the feed button on KP307 → it prints a small slip showing its IP address (e.g. 192.168.1.50).

Step 3 — Download and Install QZ Tray
They go to qz.io, download the free installer (~15MB), run it. It installs and starts automatically. It shows up as a small icon in the Windows system tray — they never need to open it again.

Step 4 — Enter Printer IP in Your POS Settings
They log into your POS, go to Printer Settings, type in 192.168.1.50, click Save. That's it.

Part 3 — Every Day After That
PC turns on → QZ Tray starts automatically in background
Cashier opens your POS in Chrome/Edge
POS connects to QZ Tray silently (user sees nothing)
Cashier takes order, clicks Print → bill comes out of KP307 instantly
Zero extra steps daily. Fully automatic.

What About Multiple Printers?
Many restaurants have 2 printers — one at billing counter, one in the kitchen (KOT printer). Same setup, just two IP addresses. Your POS would have:

Billing printer IP → bills go here
Kitchen printer IP → kitchen order tickets (KOT) go here
QZ Tray handles both from the same PC.
